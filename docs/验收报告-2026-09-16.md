- 清算真实链路（CoinGlass/AiCoin）需要 API Key + CORS 代理，当前依赖用户本地配置或浏览器转发通道，存在 Key 泄露风险。
- 模拟盘数据仅存 `localStorage`，换设备/清缓存即丢失，无法跨端同步。
- 若后续要接入真实交易或持久化账户，必须引入后端服务。
