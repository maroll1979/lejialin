数据来源与多平台口径

  • 主源（下单与撮合依据）：BTC / ETH / BNB / 黄金 一律取 Gate.io 的 USDT 永续合约价格，单一数据源、没有备线、没有现货兜底。K线、实时价、24小时涨跌、逐笔成交与实时推送全部走同一条链路，口径统一；取不到就是取不到，只会显示离线快照，绝不会拿现货价冒充永续价
  • 黄金标的：XAUUSDT 黄金永续（直接挂钩伦敦金的指数合约），不再是黄金代币 PAXG；XAU 取不到时退到 PAXGUSDT 永续，仍在 Gate 永续口径内，不会掉到现货
  • 实时推送同口径：订阅 Gate.io 期货成交流（futures.trades），与 K线、下单、强平用的是同一个市场的价，不会出现用别的市场成交价误触发限价单
  • 跨平台比价：同一品种在主源之外同时展示 OKX / Coinbase / Bitstamp 的实时价，并按「相对主源价差」排序，便于观察各平台价差（BTC/ETH 覆盖 4 家；BNB 与黄金覆盖 3 家）
  • 币种报价单位差异：Gate.io / OKX / Bitstamp 为 USDT 计价，Coinbase 为 USD 计价，两者理论上接近但存在稳定币溢价差，属正常现象
  • 价格用途区分：只有主源 Gate.io 永续的价格参与限价单撮合、强平与盈亏计算；其余平台价格仅作参考比价，不参与成交判定
  • 永续与现货的差异：永续价格围绕现货上下浮动（资金费率导致），两者通常相差几十到几百点不等；本终端以永续为唯一基准，K线、信号、止盈止损与撮合全部使用同一口径
  • 美债 2Y/5Y/10Y：美国财政部每日国债收益率曲线（单一来源，日频数据，无多平台概念，界面标注为「美国财政部」）
  • 多空清算图（K线左侧）：取自 Gate.io 永续的真实强平订单（/futures/usdt/liq_orders），按成交价位分桶累计成横向强度条，画在 K 线左侧（Y 轴左）。绿色=多头仓位被强平（强平单卖出成交，形成下杀压力），红色=空头仓位被强平（强平单买入成交，形成上冲压力）；强度条越长=该价位附近累计爆仓金额越大。金额口径 = |张数| × 合约面值 × 成交价（名义 USDT）。统计窗口可在图表头部切 24h / 3天 / 7天
  • 历史爆仓会保留：抓到的强平订单写入浏览器本地缓存（localStorage，按合约保留 7 天），重新打开页面先立刻画出本地已有的历史，再补齐最近 24 小时，随后在后台分块回补到 7 天——不是只有页面开着时才累积
  • 清算价位横线：在强度最高的若干个价位上自动画虚线横贯 K 线，并在左端标注「价位 · 多头/空头爆仓 $金额」，即把清算价位与图上价格一一对应；缩放或平移 K 线时按当前可见价格区间重新聚合。接口单次只能查 1 小时窗口，因此按小时切片并发回溯后再合并去重；每 60 秒增量刷新最近 2 小时
  • K线交互：鼠标滚轮上下缩放、按住图表左右拖动平移、Shift+滚轮横向滚动、拖动时间轴或价格轴缩放、双击轴复位；也可用图表头部的「－ / ＋ / 复位」按钮。数据自动刷新时不再重置你的缩放位置（只有换品种或换周期才重新铺满）
  • 止盈止损的三套盈亏比口径：卡片里同时给出参考价口径（方案参考价 P）、预计入场价口径（入场区中点，挂单实际面对的风险收益）与扣费净口径（再扣掉开仓与平仓两道手续费，市价 0.10% / 限价 0.05%）。三者不一致时以净口径为准；maxAtrK 是最终风险的硬上限，ATR 回退分支同样受它约束
  • 石油 / 美股 / A股：免费实时接口存在跨域与授权限制，未纳入本版本；模型可平滑扩展

数据刷新（页面右上角刷新控件）

  • 立即刷新：点击按钮或按 R 键，强制重新拉取 K线、四周期信号、涨跌热力矩阵、成交热力图与实时价格。
  • 刷新档位：实时 / 5分钟 / 10分钟 / 30分钟，选择后会记住（下次打开沿用），右侧显示到下次自动刷新的倒计时。
  • 档位只作用于行情与分析数据（K线、信号、止盈止损区间、两张热力图）。
  • 实时价格与挂单撮合、强平检查固定为 5 秒，不随档位变慢 —— 否则限价单触发与风控会失效。
  • 各档位的实际节奏：实时 = 信号/矩阵 60 秒、成交热力图 15 秒；5 / 10 / 30 分钟 = 两者同为 5 / 10 / 30 分钟。

信号模型（多因子打分，-1 ~ +1）

  • 趋势因子（权重40%）：EMA9 / EMA21 多空排列与乖离
  • 动能因子（权重25%）：MACD(12,26,9) 柱状线方向与金叉死叉
  • 超买超卖（权重20%）：RSI(14)，<30 超卖偏多，>70 超买偏空
  • 波动通道（权重15%）：布林带(20,2) %B 位置，触及上下轨提示回归
  • 综合分 ≥0.5 强烈买入 · 0.2~0.5 买入 · -0.2~0.2 观望 · -0.5~-0.2 卖出 · ≤-0.5 强烈卖出

热力图（方向与交易区间判断）

  • 多品种多周期热力图：每个品种在 15m/30m/1h/4h 四列显示该周期最近一根K线的涨跌，最右列显示近 24 小时涨跌，绿涨红跌，颜色深浅=幅度大小（±3% 以上满色）
  • 成交热力图（当下逐笔口径）：直接取该品种最近 15 分钟的真实逐笔成交（Gate.io 永续成交流），按成交价分档累计成交量后再堆积成柱。颜色越亮=当下该价位成交越密集；POC=当下成交最密集价（价格磁吸位），VA70=覆盖当下 70% 成交量的价值区间。每 15 秒自动重取一次，并显示笔数、总量与主动买/卖占比
  • 取数规则：从最新一笔成交向前回溯，最多翻 8 页×1000 笔；成交极活跃（如 BTC）时优先保证最新成交完整，并在标题栏标注实际覆盖时长。逐笔不足 20 笔时自动降级
  • 口径说明：成交热力图不再是长周期K线统计，只反映「现在」在哪成交得最多；美债无逐笔成交数据，自动降级为日线K线口径并在标题栏标注
  • 交易区间卡片：结合 近20根高低点 / ATR(14) / 布林带 推导支撑位与压力位，并用「现价 vs 当下POC」判断方向偏向

止盈 / 止损价格区间（信号栏内提示）

  • 数据依据：对 15分钟 / 30分钟 / 1小时 / 4小时 四个周期的真实K线分别计算 ATR(14) 波动、近 N 根结构高低点（15m 取20根、30m 24根、1h 30根、4h 40根）、布林带(20,2) 与多因子信号方向
  • 止损价：优先取「结构止损」（做多 = 近期最低点再让 0.15×ATR，做空 = 近期最高点再让 0.15×ATR）；若该止损距离超过单笔风险上限（15m 2.0×ATR、30m 2.2、1h 2.4、4h 2.8），则改用 ATR 止损（1.2/1.5/1.8/2.4 × ATR），避免单笔风险过大
  • 止盈价：止盈一 = 1R（1 倍风险距离）；止盈二 = 结构压力/布林上轨（做空为结构支撑/布林下轨）与 2R 中更近且可达者，否则退回 2R；同时给出止盈三（3R 以上）供参考
  • 盈亏比：以止损距离为 1R 衡量，显示 1:1 / 1:x；单笔风险列为该周期止损距离占现价的百分比
  • 参考入场区：做多为现价下方 0.12~0.60×ATR（回踩买入），做空为现价上方同样区间（反弹卖出），天然符合「限价单须挂在未触及一侧」的规则
  • 综合结论：按周期权重（15m 20% / 30m 24% / 1h 26% / 4h 30%）加权同向周期的绝对价位，给出综合止损/止盈与盈亏比；置信度 = 方向一致性 60% + 信号强度，若 2 个以上周期为震荡则下调；共振 3/4 周期同向时标注「四周期共振」
  • 建议数量：按单笔风险预算（总权益 2%）÷ 止损距离反推，并受当前杠杆下最大可开量限制
  • 持仓提示：当前品种的持仓会按所选周期的方案列出参考止损/止盈与状态（接近止损 / 接近止盈 / 持有观察）
  • 一键填入：列表内「用此方案」只把委托价与数量填进下单面板，不会自动下单，仍需手动点击买入/卖出并完成二次确认

交易规则（模拟盘 · 手动下单）

  • 订单类型：市价单（立即按最新成交价成交，Taker 手续费 0.10%）／限价单（只挂单，绝不立即成交，Maker 手续费 0.05%）。限价单必须挂在行情尚未到达的一侧：买入价须低于现价、卖出价须高于现价；提交后进入「当前委托」等待，只有实时成交价真正走到委托价才撮合成交，未成交前可随时撤单，撤单时冻结的保证金全额退回
  • 限价单撮合依据：以逐笔实时成交数据为准（优先 WebSocket 逐笔成交推送，断线时用行情轮询兜底），委托成交价 = 委托价；下单瞬间的现价不计入触发，因此不会出现「挂单即成交」
  • 方向：买入/开多、卖出/开空双向持仓；多空可同时持有，各自独立计算保证金与强平价
  • 杠杆倍数：简化档位 1x / 10x / 20x / 50x（已去掉 2x / 3x / 5x），逐仓保证金。占用保证金 = 名义价值 ÷ 杠杆；收益率按保证金计算（放大倍数）
  • 强平规则：当浮动亏损逼近保证金（预留 0.5% 维持保证金）时自动强制平仓，剩余保证金退回可用余额
  • 平仓：持仓表点「平仓」，可选 市价平仓（立即成交）或 限价平仓（转为挂单，行情真正涨/跌到委托价才成交；多单委托价须高于现价、空单须低于现价）；支持按 25%/50%/75%/100% 部分平仓
  • 反手：一步市价平掉当前持仓并反向开立等量新仓
  • 二次确认：买入、卖出、平仓、反手、撤单、重置账户均弹出确认框，须点「是 · 确认」才执行，点「否 · 取消」或按 Esc 则放弃
  • 初始模拟资金 100,000 USDT，全部数据保存在浏览器本地，可随时重置；仅手动下单，不含任何自动交易
